## WeKnora 导入建议

1. 新建“文档型知识库”，优先整目录上传 `00-导航` 到 `05-导入与溯源`。
2. 再上传 `sources/`，使回答可回溯到立项原文和原始截图。
3. 推荐标签：`AgentKit`、`Agent-Infra`、`Sandbox`、`Runtime`、`MCP`、`Skills`、`Memory`、`Knowledge-Base`、`Observability`、`Evaluation`、`Security`。
4. 对“沙箱如何隔离”“能力依赖关系”“为什么 Agent Runtime 是 Infra 核心”等高频问题，可从本仓库的专题 Markdown 直接生成 FAQ。

## 维护原则

- 原始材料不改写，结构化文档只做归纳、关联和明确标注的推断。
- 结论文档中以“来源事实”和“分析判断”区分，避免把规划当成已上线能力。
- 不纳入任何真实密钥、Token、内网地址、个人身份信息或客户数据。
