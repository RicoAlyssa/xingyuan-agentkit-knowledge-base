# 星源 AgentKit 项目立项摘要

## 一句话定位

星源 AgentKit 是金山云面向企业级 AI 应用的全栈 Agent 开发、运行和管理底座。它将 Agent Runtime、安全 Sandbox、Skills 中心、MCP 工具、记忆库、知识库、评测与可观测连接为一个全生命周期平台。

## 要解决的核心问题

| 企业痛点 | 对应能力 | 预期价值 |
| --- | --- | --- |
| 复杂 Agent 开发链路长、资源调度复杂 | AgentEngine CLI/SDK、Runtime、Serverless | 开发者聚焦业务逻辑，减少底层工程负担 |
| 工具与老旧业务系统碎片化 | MCP 广场与自定义 MCP | 按统一协议接入和复用企业工具 |
| 代码执行和数据处理有安全外溢风险 | 深度 Sandbox、日志追溯 | 隔离代码、浏览器和文件操作，缩小攻击面 |
| 模型没有长期上下文、容易幻觉 | 记忆库、RAG 知识库 | 让回答可基于历史与企业资料 |
| 上线效果和成本难以量化 | Trace、评测、运行与资源监控 | 可观察、可评估、可优化 |

## 目标客户与典型场景

1. **强合规政企**：金融、政务、国央企、医疗。关键诉求是数据不出域、执行隔离、可审计；典型场景是复杂业务自动化数字员工和政务/金融助手。
2. **追求敏捷交付的 ISV 与 SaaS 团队**：关键诉求是开发效率、弹性资源与效果验证；典型场景是 IT 运维机器人、客服和行业专属 SaaS 智能体。
3. **金山集团及云原生内部生态**：关键诉求是资产沉淀、跨业务线复用；典型场景是 WPS 办公协同 Agent、资源智能调度和共享能力中枢。

## 差异化叙事

- **安全**：以 Sandbox 隔离为企业场景提供可控执行面。
- **开放**：优先 MCP 标准化，降低工具绑定和集成碎片化。
- **智能**：记忆和知识库服务于任务连续性、检索增强和质量控制。
- **轻量敏捷**：依托 Serverless/云资源调度，降低部署和运维门槛。

## 商业与成本边界

- 收入：KCF/Serverless 实例与调用、存储、云主机、知识/记忆计算存储、模型 Token 等资源消耗，以及平台授权。
- 成本：跨框架适配、Sandbox 隔离、多模态检索、云函数迭代、镜像预热池与观测数据处理。
- 产品判断：Sandbox、Runtime 资源调度和可观测既是差异化能力，也是最需要持续投入的成本中心。

## 路线图摘要

| 能力 | 2026 Q1 | 2026 Q2 规划/扩展 |
| --- | --- | --- |
| Agent 运行时 | CLI/SDK、控制台、部署 OpenClaw | 运行/资源/事件监控、底层资源切换、OpenClaw 接入 Skills 和 Mem0 |
| 可观测 | Langfuse 集成 | 运行时与知识/记忆/沙箱的可观测完善 |
| Sandbox | - | 标准模板、Skill 执行、预热、实例操作、存储挂载、日志监控 |
| Skills | - | 空间、Skill 管理与 SkillHub |
| MCP | 广场、自定义服务、管理、鉴权 | 远程调用、客户 API Key、内部 MCP、运行时监控、工具集 |
| 记忆库 | 创建/管理、提取策略 | 会话与策略管理、自动匹配、Mem0、监控 |
| 知识库 | 创建/管理、切片查询/召回、云端与大数据集成 | 控制台优化、PDF 预管理、多文件导入、RAG Agent、租户隔离与计费 |
