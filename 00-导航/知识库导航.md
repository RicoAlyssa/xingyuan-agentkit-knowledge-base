## 推荐阅读路径

1. 产品负责人：项目立项摘要 → 总体架构 → 实施治理与验收。
2. 平台/Infra 工程师：总体架构 → Agent Infra 分析 → Runtime → Sandbox → 可观测与评测。
3. Agent 应用工程师：Runtime → Skills → MCP → 记忆与知识库 → Sandbox 使用边界。
4. 安全与运维人员：Sandbox → 实施治理与验收 → 可观测与评测。

## 核心术语

- **Agent Runtime / AgentEngine**：执行、编排、部署和资源调度的控制面与数据面。
- **Sandbox**：承载代码、浏览器和 Skill 执行的隔离运行环境。
- **Skills**：可复用的任务能力包，包含指令、脚本、参考资料与资产。
- **MCP**：工具接入标准，允许 Agent 以统一协议发现和调用外部系统能力。
- **记忆库**：跨轮、跨任务沉淀并召回用户或业务上下文的服务。
- **知识库**：对文档进行解析、分块、检索和引用的 RAG 基础服务。
